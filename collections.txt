****ArrayList****

//Characteristics

-->ArrayList is a resizable array.
-->Stores elements in insertion order.
-->Allows duplicate elements.
-->Provides fast random access using indexes.
-->Automatically resizes when elements are added or removed.
-->Does not store primitive data types directly (use wrapper classes like Integer, Double, etc.).

#Syntax.

import java.util.ArrayList;
ArrayList<DataType> list = new ArrayList<>();

// Add elements
    fruits.add("Apple");

// Display elements
    System.out.println(fruits);

// Access an element
    System.out.println(fruits.get(1));

// Update an element
    fruits.set(1, "Mango");

// Remove an element
    fruits.remove("Orange");

// Size of the list
    System.out.println(fruits.size());

// Iterate through the list
    for (String fruit : fruits)
    {
      System.out.println(fruit);
    }
    

****HashMap****

//Characteristics

-->Stores data as key → value pairs.
-->Keys are unique.
-->Values can be duplicated.
-->Allows one null key.
-->Allows multiple null values.
-->Does not maintain insertion order.
-->Average time complexity for put(), get(), and remove() is O(1).
