-----Sorting-----

**Selection Sort**

->Assume the initial element as min and swap with the actual min.

//code.
 for(int i=0;i<n;i++)
{
    for(int j=i+1;j<n;j++)
    {
        if(arr[i]>arr[j])
        {
            int t=arr[i];
            arr[i]=arr[j];
            arr[j]=t;
        }
    }
}

**Bubble Sort**

->push the max to last by adjacent swaps.

//code
for(int i=n-1;i>0;i--)
{
    for(int j=0;j<=i-1;j++)
    {
        if(arr[j]>arr[j+1])
        {
            int t=arr[j];
            arr[j]=arr[j+1];
            arr[j+1]=t;
        }
    }
}
