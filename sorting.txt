-----Sorting-----

**Selection Sort**

-->"Find the smallest, then swap".

*Logic*

-->Find the smallest element in the unsorted part.
-->Swap it with the first unsorted position.
-->Repeat.

**Time complexity**
-->O(N^2)

//code.
 for(int i=0;i<n;i++)
{
    for(int j=i+1;j<n;j++)
    {
        if(arr[i]>arr[j])
        {
            int t=arr[i];
            arr[i]=arr[j];
            arr[j]=t;
        }
    }
}

**Bubble Sort**

->push the max to last by adjacent swaps. or Air bubbles in water rise to the surface.

*Logic*

-->Compare adjacent elements.
-->Swap if they are in the wrong order.
-->After one pass, the largest element reaches the end.

**Time complexity**
-->O(N^2)

//code
for(int i=n-1;i>0;i--)
{
    for(int j=0;j<=i-1;j++)
    {
        if(arr[j]>arr[j+1])
        {
            int t=arr[j];
            arr[j]=arr[j+1];
            arr[j+1]=t;
        }
    }
}

**Insertion Sort**

->Arranging playing cards in your hand.

*Logic*

-->Pick one element.
-->Compare it with the sorted left side.
-->Shift larger elements to the right.
-->Insert the picked element in the correct position.

**Time complexity**
-->O(N^2)

// Code
for(int i=0;i<n;i++)
{
    int j =i;
    while(j>0&&arr[j-1]>arr[j])
    {
        int t=arr[j];
        arr[j]=arr[j-1];
        arr[j-1]=t;
        j--;
    }
}

**Merge Sort**

-->Divide and Merge.

**Time complexity**
-->O(N*log ​N)

//code

static int[] mergesort(int[] arr,int l,int h)
{
    if(l>=h){ return arr;}
    int mid =(l+h)/2;
    mergesort(arr,l,mid);
    mergesort(arr,mid+1,h); 
    merge(arr,l,h,mid);
    return arr;
}
static void merge(int[] arr,int l,int h,int mid)
{
    int nums[]=new int[h+1];
    int left=l;
    int right=mid+1;
    int k=0;
    while(left<=mid && right<=h)
    {
        if(arr[left]<arr[right])
        {
            nums[k++]=arr[left];
            left++;
        }
        else
        {
            nums[k++]=arr[right];
            right++;
        }
    }
    while(left<=mid)
    {
        nums[k++]=arr[left];
        left++;
    }
    while(right<=h)
    {
        nums[k++]=arr[right];
        right++;
    }
    for(int i=l;i<=h;i++)
    {
        arr[i]=nums[i-l];
    }
}
