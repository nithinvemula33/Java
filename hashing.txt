---Hashing---

-->Hashing in Java is a technique used to store and retrieve data efficiently using a hash function.
-->It is widely used in collections like HashMap, HashSet, and Hashtable.

*how hashing works

-->A key is passed to a hash function.
-->The hash function generates a hash code (an integer).
-->The hash code determines the index (bucket) where the data is stored.
-->When retrieving data, the same hash function computes the index, making lookup very fast.
